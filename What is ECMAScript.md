ECMAScript (ES) is a standardized scripting language specification that JavaScript is based on. It defines the core features and syntax of JavaScript to ensure consistency across different implementations.

### Key Points:

- **Purpose**: To standardize JavaScript so it works similarly in different environments.
- **Maintained by**: ECMA International (a standards organization).
- **Versions**: Major updates include ES5 (2009), ES6 (2015), and yearly releases since then (e.g., ES7, ES8).
- **Features**: Introduced features like arrow functions, classes, promises, async/await, modules, etc.
- **Other Languages**: Similar languages like JScript (Microsoft) and ActionScript (Adobe) also follow the ECMAScript standard.
