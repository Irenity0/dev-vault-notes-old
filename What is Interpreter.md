### **Interpreter**

An **interpreter** is a program that directly executes code line by line without converting it into machine code beforehand.

### **Interpreted Language**

A language is called **interpreted** when its code is executed by an interpreter rather than being compiled into machine code.

---

### **Key Features of Interpreted Languages**:

- **Line-by-Line Execution**: Executes one instruction at a time.
- **No Compilation Step**: Easier debugging but slower execution compared to compiled languages.
- **Dynamic Typing**: Many interpreted languages allow more flexibility at runtime.

### **Examples**:

- **Interpreted Languages**:
    - JavaScript (browser runtime, Node.js).
    - Python (Python interpreter).
    - Ruby.
    - PHP.
- **Languages with Both**: Some languages (like Java) use both compilation (to bytecode) and interpretation (e.g., JVM executes Java bytecode).

---

### **Pros of Interpreted Languages**:

- Easier debugging and testing (no recompilation needed).
- Platform independence (runs in any compatible runtime).
- Good for scripting, prototyping, and web development.
